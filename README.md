# Online-Book-Store-

## 📌 Project Overview
This project focuses on managing and analyzing an Online Book Store database using SQL to extract meaningful business insights. The project involves analyzing book inventory, customer orders, sales transactions, and customer purchasing patterns by executing SQL queries. It helps understand business performance, identify popular books, and evaluate revenue generation.

## 🎯 Objectives
- Analyze overall sales performance and revenue generated from book purchases.
- Identify the best-selling books and popular book categories.
- Analyze customer purchasing behavior and order patterns.
- Track book inventory and identify available stock.
- Identify top-spending customers based on purchase history.
- Generate meaningful business insights using SQL queries.

## 🛠 Technologies Used
- SQL
- SQL Server Management Studio (SSMS)
- CSV Dataset

## 📊 Key Analysis Performed
- Total revenue generated from book sales.
- Best-selling books based on quantity sold.
- Most popular book categories.
- Customer-wise order analysis.
- Top customers based on total spending.
- Book inventory and stock availability.
- Order and sales transaction analysis.

## 💡 Key Learnings
- Database creation and table management.
- Data retrieval and filtering using SELECT, WHERE, and ORDER BY.
- Data aggregation using SUM, COUNT, AVG, MIN, and MAX.
- Joining multiple tables to retrieve related information.
- Using GROUP BY and HAVING for analytical queries.
- Applying subqueries and CTEs to solve business problems.
- Extracting meaningful insights from relational databases.
